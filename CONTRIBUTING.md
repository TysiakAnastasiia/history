# Як додати тему

Інструкція для тих, хто наповнює тренажер контентом. Еталон — **тема 3** (`content/hist-ua/topic-03`): коли щось незрозуміло, дивіться, як зроблено там.

## Коротко

1. Гілка: `git checkout -b content-topic-NN`.
2. Тека `content/hist-ua/topic-NN/` (NN — двозначний номер: `topic-04`) з файлами нижче.
3. `npm run validate` — поки не з'явиться `✓ Контент у порядку`.
4. `npm run dev` — переглянути тему на сайті.
5. Коміт англійською, push, Pull Request у `main`. Власниця теми переглядає й затверджує.

Тема з'являється на сайті сама, щойно в теці є питання або теорія — нічого в коді міняти не треба.

| `maps.json`      | шари історичних карт                                               | якщо в програмі є картосхема                |

## program.json — почніть з нього

Перенесіть із програми МОН (наказ № 696 від 26.06.2018) дати, персоналії, терміни, пам'ятки й пункти картосхеми **дослівно**. `npm run validate` перевіряє, що кожен пункт є і в теорії, і в питаннях (картосхема — лише в теорії), і падає з переліком пропущеного.

```json
{
  "source": "Програма ЗНО з історії України, наказ МОН № 696 від 26.06.2018, тема 4 «…»",
  "dates": [{ "year": "1240", "text": "захоплення Києва монголами" }],
  "persons": [{ "name": "Данило Романович", "match": ["Данил"] }],
  "terms": [{ "name": "ярлик" }],
  "monuments": [{ "name": "…", "match": ["…"] }],
  "map": [{ "name": "походи Батия", "match": ["Батия"] }]
}
```

`match` — фрагменти для пошуку в тексті, коли слово змінюється за відмінками (`Данил` знайде і «Данило», і «Данила»).

## facts.json — довідник

```json
{
  "id": "hist-ua.t04.f-1240",
  "kind": "event",
  "year": 1240,
  "title": "Захоплення Києва монголами",
  "source": "Програма МОН № 696 (2018); Земерова Т. … (2022)",
  "status": "draft"
}
```

- `kind`: `event` (подія), `person` (діяч), `term` (термін), `monument` (пам'ятка), `place`.
- **Події:** рік у `year`, у `title` — без року (картки на пам'ять і хронологія ховають роки в дужках, але краще їх не писати). Події з роками одразу потрапляють у «Картки на пам'ять» і «Хронологію».
- **Терміни:** `title` — сам термін, `details` — визначення простими словами (воно ж — підказка в «Шибениці»).
- **Діячі:** `details` — коротка довідка; `hints` — 5 підказок для гри «Хто я?» від найзагальнішої до найконкретнішої, від першої особи. Ім'я в підказках не згадувати.

```json
"hints": [
  "Я був ченцем.",
  "Я жив у печерах над Дніпром.",
  "Мене зображено на Свенській іконі разом із Феодосієм.",
  "Близько 1051 р. я заснував у Києві монастир.",
  "Я — засновник Києво-Печерського монастиря."
]
```

## theory.json — теорія

Кожен розділ — короткий, простою мовою, абзацами по 2–4 речення.

```json
{
  "id": "s1",
  "title": "Назва розділу",
  "body": ["Абзац 1.", "Абзац 2."],
  "remember": "Найважливіше одним-двома реченнями.",
  "check": ["hist-ua.t04.q001", "hist-ua.t04.q007"],
  "media": ["t04-danylo-crown"],
  "maps": ["t04-mongols"]
}
```

- `check` — 3–6 питань для блоку «Перевір себе» (різних типів).
- `media`, `maps` — необов'язкові.
- Порядок розділів у файлі = порядок на сайті.

## questions.json — питання

Спільні поля для всіх типів:

| Поле               | Що це                                                    |
| ------------------ | -------------------------------------------------------- |
| `type`             | `single`, `matching`, `sequence`, `multi3of7`, `mapPick` |
| `topic`, `section` | номер теми й розділ для «Читати далі»                    |
| `prompt`           | текст питання                                            |
| `short`, `why`     | «Коротко» і «Чому так» — обов'язково                     |
| `mnemonic`         | «Як запам'ятати» — дуже бажано                           |
| `facts`            | id фактів, на які спирається питання                     |
| `image` / `map`    | зображення або картосхема над питанням (необов'язково)   |
| `status`           | `draft`, після затвердження — `verified`                 |

Типи (як на НМТ):

- **single** — 4 варіанти, `answer` — індекс правильного (0–3). У **кожного неправильного** варіанта `note` — чому він неправильний (валідатор це перевіряє).
- **multi3of7** — 7 варіантів, `answer` — три індекси; `note` у чотирьох неправильних.
- **matching** — `left` (4 пункти), `right` (5 варіантів, один зайвий), `answer[i]` — індекс у `right` для `left[i]`. У `why` поясніть, чому зайвий варіант зайвий.
- **sequence** — `items` (4 події), `answer` — індекси `items` у правильному порядку. Не записуйте `items` уже в правильному порядку.
- **mapPick** — «Покажіть на картосхемі»: `layer` — id шару, `answer` — id області. Лише для тренувань, у пробний НМТ не потрапляє.

Орієнтир на тему: 80–120 питань, приблизно 70 % `single`, решта — інші типи. Пишіть **власні** питання: з сайтів і посібників не копіюємо.

## maps.json — карти

Основа карти (узбережжя, річки) уже є. У шарі описуєте лише своє: області, маршрути, міста — координатами `[довгота, широта]`.

```json
{
  "id": "t04-mongols",
  "title": "Монгольська навала (1237–1241)",
  "description": "Межі схематичні.",
  "view": [21.5, 44.6, 40.0, 56.0],
  "regions": [
    {
      "id": "halych",
      "name": "Галицьке",
      "note": "Центр — Галич",
      "points": [
        [22.5, 49.8],
        [25.2, 49.7],
        [24.6, 47.6]
      ]
    }
  ],
  "routes": [
    {
      "id": "batu",
      "name": "Похід Батия",
      "points": [
        [45.0, 54.0],
        [30.5, 50.45]
      ],
      "dashed": false
    }
  ],
  "cities": [{ "name": "Київ", "at": [30.52, 50.45], "capital": true }]
}
```

- `view` — межі показу: `[довгота мін, широта мін, довгота макс, широта макс]` у межах 20.5–50.5° сх. д. і 40.3–61.5° пн. ш.
- Координати міст беріть з Вікіпедії; межі областей — схематично, звіряючи з картою в посібнику (5–10 точок досить, лінії згладжуються автоматично).
- `label` — де підписати область, якщо підпис налазить на місто.
- Перевіряйте карту на сайті: розділ теорії з `maps` або питання з `map`.

## quotes.json — цитати

Для гри «Хто це сказав?». Короткі відомі вислови з літописів і творів епохи — у сучасному українському переказі.

```json
{
  "id": "hist-ua.t04.quote-001",
  "text": "Текст цитати без лапок.",
  "author": "Данило Романович",
  "context": "Коли, кому й чому це сказано — одним-двома реченнями.",
  "source": "Галицько-Волинський літопис",
  "status": "draft"
}
```

`author` — ім'я або опис («Древляни», «Автор «Слова о полку Ігоревім»»). Щоб гра працювала, потрібно щонайменше 4 різні автори (з усіх тем разом).

## journey.json — сюжет для «Подорожі епохами»

Мандрівник у часі з котом-провідником відвідує місця подій на карті епохи й розмовляє з персонажами. Повний приклад — `content/hist-ua/topic-03/journey.json`.

- `characters` — персонажі: `name`, `role`, `look` (портрет: `prince`, `elder`, `warrior`, `helmet`, `princess`, `monk`, `chronicler`) і `color` одягу.
- `scenes` — 6–10 сцен у хронологічному порядку: `place`, `year`, `at` (координати), `character`, репліки `lines` (`who` — id персонажа або `guide` для кота), запитання `ask` з 3 варіантами (рівно один `correct`, у кожного `reply` — реакція персонажа, у неправильних вона ще й пояснює, як було насправді), `outro` і нагорода `reward` (`name`, `about`, необов'язково `image` з media.json).
- `boss` — фінал: персонаж, вступ, 5 id питань формату НМТ (`matching`, `sequence`, `multi3of7`), `pass` (скільки треба правильних) і репліки `win` / `lose`.
- `intro` — вступ кота до епохи; `view` — межі карти епохи.

Пишіть живо, але факти — лише перевірені: персонажі «говорять» те, що є в програмі й посібнику.

## Зображення

1. Шукайте на [Вікісховищі](https://commons.wikimedia.org) (суспільне надбання, CC0 або CC BY / CC BY-SA). **З посібників і сайтів не беремо** — репозиторій публічний.
2. Зменшіть до ~760 px і збережіть як WebP у `public/media/tNN/назва.webp` (до ~150 КБ).
3. Додайте запис у `content/hist-ua/media.json`:

```json
{
  "id": "t04-kholm",
  "file": "t04/kholm.webp",
  "title": "Що зображено (дата), сучасний вигляд",
  "author": "Автор з Вікісховища",
  "license": "CC BY-SA 4.0",
  "licenseUrl": "https://creativecommons.org/licenses/by-sa/4.0",
  "source": "https://commons.wikimedia.org/wiki/File:…"
}
```

Автор і ліцензія показуються під зображенням автоматично — для CC BY-SA це обов'язково.

## Правила змісту

- Пишемо **своїми словами**, простою мовою, як для учня 11 класу.
- Факти перевіряємо за програмою й посібником; у `source` вказуємо, звідки.
- Нове — зі статусом `draft`. Після перегляду власниця теми змінює на `verified`.
- Назви — як у програмі МОН (наприклад, «древляни», «Русь-Україна»).

## Перед Pull Request

```bash
npm run validate      # контент і покриття програми
npm run lint
npm run build
npm run format        # відформатувати JSON і код
```

Якщо `validate` падає — читайте перелік помилок: там написано файл, id і що не так.
